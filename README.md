# CineVerse

Aplicativo de streaming desenvolvido com React Native, Expo e Node.js.

## Funcionalidades
- Login e cadastro
- Catalogo de filmes e series
- Pesquisa e favoritos
- Gerenciamento de perfil
- Avaliacoes e reproducao de videos
- Integracao com API REST

## Tecnologias
- React Native
- Expo
- JavaScript
- Node.js

## Estrutura
- frontend/: aplicativo mobile
- backend/: servidor e API

## Executar o frontend
cd frontend
npm install
npx expo start

## Executar o backend
cd backend
npm install

Configure as variaveis de ambiente conforme backend/.env.example.
